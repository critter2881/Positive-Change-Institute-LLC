REST API Reference

The backend exposes a versioned HTTP API. All responses are JSON. Run GET /health to verify connectivity.

GET
/health
Liveness and readiness probe. Returns {"status":"ok"}.
GET
/api/divisions
Returns all registered divisions and their associated product IDs.
GET
/api/wallets
Returns the public wallet registry with chain and address metadata.
GET
/api/product_metadata
Resolves a wallet + product_id pair to division metadata.
GET
/api/real_time_liquidity
Returns simulated real-time liquidity pool depths across all divisions.
