# Doctrine Archive

This folder consolidates the doctrine repositories that were created earlier into this single system of record. Each page keeps the substance of the original and links to the source repository, so nothing is lost when those repositories are archived.

> **How to read these pages.** Doctrine pages describe PCI's *intended* architecture and standards. Statements such as "absolute operational integrity" or "10/10 or reject" are **design principles and positioning**, not measured results. Where a page describes code that is not in this repository, it says so.
