| **Doctrine** | PCI's rule set for governance (white paper) and for APO |
| **FDV** | Fully diluted valuation: supply × price |
| **MiCA** | EU Markets in Crypto-Assets Regulation |
| **NFTokenMint** | The XRPL transaction used to mint Arcana NFTs |

| **Product ID** | Unique identifier such as `PCI_AI_001` (divisions) or `FORGE-001` (NFTs) |
| **Prometheus** | PCI's AI orchestration layer |
| **Registry** | A canonical JSON file under `config/` |
| **Resilience score** | Capped 0–100 score from the DeFi analysis service |
| **Source of truth** | This repository. One canonical copy of every fact |
| **TTL cache** | Time-limited in-memory cache (60 s) used for liquidity data |
| **XRPL** | The XRP Ledger |
